#SIMPLIFIED AIRCRAFT TURBULENCE RISK ESTIMATOR

The Simplified Aircraft Turbulence Risk Estimator is a Python-based educational project that estimated the turbulence risk level of an aircraft using selected flight and atmospheric parameters.

##Project description

The program takes inputs such as altitude,aircraft speed,temperature change and wind speed change.It then calculates atmospheric conditions,Mach number,wind shear and a turbulence score.
Based on the calculated score,the program gives an estimated turbulence risk as LOW,MODERATE or HIGH.
This is a simplied educational model and is not an operational aviation turbulence prediction system. 

##Features

-Calculates atmospheric temperature
-Calculates atmospheris pressure
-Calculates air density
-Calculates speed of sound
-Calculates Mach number
-Identifies the flight regime
-Calculates wind shear
-Calculates turbulence score
-Estimates turbulence risk
-Provides basic input validation
