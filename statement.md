#Project statement

##Problem Statement

Aircraft turbulence can be influenced by different atmospheric and flight conditions such as wind speed,wind shear,temperature changes,altitude and aircraft speed.
The purpose of this project is to develop a simple python-based program that uses selected flight and atmospheric parameters parameters to calculate a turbulence score and provide an estimated turbulence risk level.
The project is designed as an educational model to demonstrate how python programming concepts can be applied to an aerospace engineering problem.

##Scope

The project focuses on estimating turbulence risk using;
-Aircraft altitude
-Aircraft speed
-Temperature change
-Wind speed
-Wind speed change
-Wind shear
-Mach number
The program calculates atmospheric conditions and combines selected parameters into a turbulence score.
The final risk is classified into:-
-LOW
-MODERATE
-HIGH
The project does not provide real-time aviation weather predictions and is not intended for operational aircraft safety decisions.

##Target Users

The project is mainly intended for:-
-Aerospace engineering students
-Students learning python programming 
-Engineerings interested in aircraft performance
-Students interested in basic atmospheric and flight calculations

##High-level features

-Accepts aircraft and atmospheric inputs from the user.
-Performs atmospheric calculations.
-Calculates the speed of sound.
-Calculates mach number.
-Identifies the flight regime.
-Calculates wind shear.
-Calculates a turbulence score.
-Estimates the turbulence risk level.
-Performs basic input validation.
Displays the calculated results through the command line.

##expected outcomes

the expected outcome of the project is a simple command-line python program that demonstrates the relationship between selected atmospheric and flight parameters and provides an educational estimates of turbulence risk.
